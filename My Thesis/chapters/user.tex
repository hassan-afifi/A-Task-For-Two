\chapter{User Documentation}

\section{Short Problem Statement}
This application provides a cooperative two-player puzzle experience in which each participant has only partial information. The task can only be completed if both users communicate and set the correct puzzle values together.

\section{Brief Method Overview}
The system is based on synchronized state sharing between two connected participants. Each participant sees a different puzzle view and controls one die that influences the other participant's missing value. The puzzle is considered solved only when both dice are set to the correct values and remain stable long enough for the bars to open. This design enforces coordinated interaction instead of random rapid input.

\section{System Requirements}
\subsection*{User Requirements}
The application requires a Windows-based system capable of running the Unity standalone build. A keyboard and mouse are required for interaction.

\subsection*{Development Requirements (optional)}
For development and running from source, the following tools are required:

\begin{itemize}
\item Unity Hub.
\item Unity Editor \texttt{6000.3.10f1}.
\item Git.
\item Git LFS.
\item Visual Studio Code \texttt{1.111.0}.
\end{itemize}

Platform note:
\begin{itemize}

\section{Installation and Startup}
\begin{enumerate}
\item The application can be obtained by cloning the project repository:
\begin{verbatim}
git clone https://github.com/hassan-afifi/A_Task_For_Two.git
\end{verbatim}
or
\begin{verbatim}
git clone git@github.com:hassan-afifi/A_Task_For_Two.git
\end{verbatim}

\item Enter the project folder:
\begin{verbatim}
cd A_Task_For_Two
\end{verbatim}

\item Enable and pull Git LFS assets:
\begin{verbatim}
git lfs install
git lfs pull
\end{verbatim}

\item Open Unity Hub, choose \textbf{Add project from disk}, select the cloned folder, and open it with Unity Editor \texttt{6000.3.10f1}.
\end{enumerate}

\section{Controls and Interaction}
The game uses standard first-person controls with keyboard movement and mouse-based camera control. Interaction with objects, such as the puzzle die, is performed using the designated interact key.

\section{Gameplay Flow}
\begin{enumerate}
\item Open the main menu and create or join a session.
\item Move to the puzzle area once both participants are connected.
\item Read your local puzzle symbols and communicate with the other participant.
\item Rotate your die to provide the value required by the other participant's puzzle.
\item Keep both dice on correct values until the bars open.
\item Move forward to complete the level and trigger the end screen.
\end{enumerate}
